# 前端模块测试说明

## 一、测试范围

本测试覆盖前端最小页面框架 v5 的核心功能，包括：

1. 页面加载与布局
2. 事件列表渲染
3. 事件详情展示
4. 处理时间线展示
5. 审批弹窗交互
6. 演示数据降级
7. 接口字段对齐

## 二、测试环境

- **操作系统**：Windows 10 / 11
- **浏览器**：Chrome 110+ / Edge 110+
- **后端状态**：可选（未启动时自动走演示数据）

2. 视觉风格尚未统一（配色、图标、字体待后续调整）。
3. 尚未对接真实后端接口，当前测试基于演示数据。
4. 未覆盖异常输入场景（如空数据、网络超时等边界情况）。
